# Rental Management System - Frontend

Frontend dashboard cho hệ thống quản lý phòng trọ theo mô hình SaaS, được xây dựng bằng Next.js và TailwindCSS.

## Live Demo

https://rental-frontend-orcin.vercel.app/

## Backend Repository

https://github.com/nguyentuankiet203/Rental

## Technologies

* Next.js
* TypeScript
* TailwindCSS
* JWT Authentication
* RESTful API
* Axios

## Features

* Authentication & Authorization
* Protected Routes
* Responsive Dashboard UI
* Room & Tenant Management
* Invoice Management
* Realtime Notification
* API Integration
* Token Storage & Session Handling

```bash
 └── types/
```

## Installation

Clone the project:

```bash
git clone https://github.com/nguyentuankiet203/rental-frontend.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

## Environment Variables

Create `.env.local`

```env
NEXT_PUBLIC_API_URL=your_backend_api
```
