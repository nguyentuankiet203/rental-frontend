# Rental Management SaaS - Frontend

A modern rental management platform built with Next.js and TypeScript.

## Features

- Authentication & Authorization
- Property Listings
- Tenant Management
- Contract Management
- Payment Tracking
- Responsive UI
- Dashboard Analytics

---

## Tech Stack

- Next.js
- TypeScript
- TailwindCSS
- Axios
- React Hook Form

---

## Installation

```bash
git clone <repository-url>
cd rental-frontend

npm install
```

Create `.env.local`

```env
NEXT_PUBLIC_API_URL=http://localhost:3001
```

Run:

```bash
npm run dev
```
